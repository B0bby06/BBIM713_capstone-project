BBIM713 — AUCKLAND AIR QUALITY PORTFOLIO
======================================

WHAT IS INCLUDED
- index.html: the complete, one-file, mobile-friendly portfolio website.
  The charts and dashboard screenshot are embedded, so no extra assets are required.
- README.txt: publication and submission instructions.

TO PREVIEW ON YOUR WINDOWS PC
1. Extract the ZIP file.
2. Double-click index.html. It will open in your web browser, even offline.
3. Review every section and ask team members to verify their own contribution statements.

ADD YOUR REQUIRED REAL LINKS
1. Right-click index.html, choose Open with > Notepad (or Visual Studio Code).
2. Press Ctrl+F and search for PORTFOLIO_LINKS.
3. Replace each empty pair of quotation marks with an HTTPS link:
      repo: "https://...",
      demo: "https://...",
      report: "https://..."
4. Save, reopen index.html and test all links.

PUBLISH FREE WITH GITHUB PAGES
1. Sign into GitHub and create a PUBLIC repository for this portfolio.
2. Upload index.html to the repository ROOT (top-level).
3. Choose Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Open the live site link shown in Settings > Pages after publication.
6. Copy this live portfolio URL into your BBIM713 final report and presentation appendix.
   Also put the portfolio URL in your project repository README.
   Make sure your tutor can open it without logging in.
